# Template usage rules

- Use one breakfast template.
- Use one lunch template.
- Use one snack template where needed.
- Add one pre-badminton template on badminton days.
- Use one dinner template.
- Use adjustment templates only when the daily total needs fine-tuning.
- Take one SuperYou scoop at home, either in the morning or at night.
- Have 200 g curd at home, preferably with the afternoon meal or dinner.
- Do not count curd or SuperYou as office foods.

The earlier day-type plans use these codes, but each day-plan table should also show the full contents beside the code. The calorie and protein values are planning estimates based on the food assumptions we established, not exact measurements.
