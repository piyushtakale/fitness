# Job Search & Profile Track

## Objective

Build a **strong professional presence** and actively apply for SDE2/SDE3 roles starting **Week 5** (after Month 1 of preparation).

## Key Principles

1. **Start Early**: Begin applying after Week 4, even if you don't feel "ready"
2. **Consistency**: 30 minutes on alternate days (not just weekly)
3. **Quality over Quantity**: Tailor applications, don't spam
4. **Build in Public**: Share progress on LinkedIn/GitHub to attract opportunities
5. **Track Everything**: Maintain application tracker, follow up systematically

---

## Phase 1: Foundation (Week 4)

### Day 1: Resume Creation (2-3 hours focused session)

**Tasks:**
- [ ] Gather all achievements, metrics, projects from past 5 years
- [ ] Choose clean resume template (1-page for <10 years experience)
- [ ] Write summary: "SDE with 5 years experience in [tech stack], passionate about [interests]"
- [ ] List experience in reverse chronological order
- [ ] For each role: 3-5 bullet points with **metrics** (e.g., "Reduced latency 30%", "Improved throughput 2x")
- [ ] Add Swiggy project (even if in progress): "Building microservices food delivery app with Spring Boot, React, AWS"
- [ ] Add skills section: Java, Spring Boot, React, AWS, System Design, DSA
- [ ] Proofread 3 times, get feedback from 2 people
- [ ] Export to PDF (filename: `FirstName_LastName_SDE2_Resume.pdf`)

**Template Structure:**
```
[Name]
[Phone] | [Email] | [LinkedIn] | [GitHub] | [Location]

Summary
2-3 lines about your experience and interests

Experience
Company 1 (Most Recent)
- Achievement 1 with metric
- Achievement 2 with metric
- Achievement 3 with metric

Company 2
- Achievement 1 with metric
- Achievement 2 with metric

Projects
Swiggy/Zepto Clone - Microservices Food Delivery App
- Built 6 microservices with Spring Boot, React, AWS
- Handled X orders/sec, deployed on ECS/Fargate
- Tech: Java, Spring Boot, React, PostgreSQL, Redis, Kafka, AWS

Skills
Languages: Java, JavaScript, TypeScript
Frameworks: Spring Boot, React
Tools: Docker, AWS, Git, Kubernetes (if applicable)
```

## Phase 2: Active Applications (Weeks 5-16)

### Routine (30 minutes on alternate days)

**Tasks:**
- [ ] Check job alerts (5 min)
- [ ] Identify 2-3 high-quality openings (5 min)
- [ ] Tailor resume for each role (10 min)
  - Adjust summary to match job description
  - Highlight relevant experience
  - Add keywords from job posting
- [ ] Submit applications (10 min)
- [ ] Update tracker (5 min)

**Weekly Target:**
- Apply to 5-10 quality roles/week
- Don't spam; focus on roles that match your skills

---

### Networking and Referrals (1-2 hours/week)

**Tasks:**
- [ ] Identify engineers at target companies (LinkedIn)
- [ ] Send personalized connection requests:

  Hi [Name],

## Success Metrics

- **Week 4**: Resume, LinkedIn, GitHub, job alerts all set up
- **Week 8**: 20-30 applications sent, 2-3 interview calls
- **Week 12**: 40-50 applications sent, 5-8 interview calls, 1-2 offers
- **Week 16**: 60-80 applications sent, 10-15 interview calls, multiple offers

---

## Important Tips

1. **Don't Wait for "Perfect"**: Start applying after Week 4, even if you feel underprepared
2. **Tailor Each Application**: Generic applications get ignored; spend 10 min customizing
3. **Follow Up**: If no response in 7-10 days, send polite follow-up
4. **Track Everything**: You'll lose track without a tracker
5. **Learn from Rejections**: Ask for feedback, improve, move on
6. **Stay Positive**: Job search is a numbers game; rejection is normal
7. **Network Genuinely**: Build relationships, not just transactional connections
