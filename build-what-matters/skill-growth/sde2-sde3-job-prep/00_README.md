# SDE2/SDE3 16-Week Elite Preparation Plan

## Overview

This is a **16-week comprehensive preparation plan** for SDE2 and SDE3 roles at top tech companies. The plan is designed for someone with ~5 years of experience who wants to:

- Master DSA patterns (300+ problems)
- Become proficient in System Design (HLD + LLD + Machine Coding)
- Build a production-grade microservices project (Swiggy/Zepto clone)
- Leverage AI tools (Cursor, Copilot, RAG, LangChain) for elite development
- Actively apply for jobs and build a strong professional profile

## Structure

The plan is organized into **separate tracks** that run in parallel:

1. **DSA Track** - Data Structures & Algorithms practice
2. **HLD Track** - High-Level Design (system architecture)
3. **LLD Track** - Low-Level Design (class-level design)
4. **Machine Coding Track** - Fully working code under time pressure
5. **Swiggy Project Track** - End-to-end microservices application
6. **Job Search & Profile Track** - Resume, LinkedIn, applications (starts Week 5)
7. **AI & Agentic Dev Track** - AI tools, RAG, LangChain, small AI projects

## Weekly Pattern

Instead of doing everything every day, each day focuses on **one main stream**:

- **Monday**: DSA Day
- **Tuesday**: Project Day
- **Wednesday**: HLD Day
- **Thursday**: LLD + Machine Coding Day
- **Friday**: AI Tools + Job Search Day (alternate days for job search after Week 4)
- **Saturday**: Deep Work Day (Project or Hard DSA)
- **Sunday**: Review + Light Practice

**Time commitment**: 3-4 hours/day on average (20-25 hours/week)

## How to Use This Plan

1. **Start with `01_16Week_Schedule.md`** - understand the weekly rhythm
2. **Each day**, open the relevant track file for detailed tasks
3. **After Week 4**, add 30 min on alternate days for job search (see `07_JobSearch_Profile_Track.md`)
4. **Every Sunday**, review your progress using `09_Progress_Tracking.md`
5. **Adjust as needed** - this is a template, not a rigid constraint

## Key Principles

- **Consistency > Intensity**: Better to do 3 hours daily than 10 hours sporadically
- **One stream per day**: Deep focus on one area instead of fragmented attention
- **AI-first development**: Use Cursor, Copilot, and AI agents to accelerate learning
- **Build in public**: Share progress on LinkedIn/GitHub to attract opportunities
- **Apply early**: Start applying after Week 4, even if you don't feel "ready"

## Timeline

- **Weeks 1-4**: Foundation (DSA basics, project setup, HLD/LLD fundamentals)
- **Weeks 5-8**: Depth (advanced patterns, project deployment, AI integration)
- **Weeks 9-12**: Mastery (hard problems, system design mastery, mock interviews)
- **Weeks 13-16**: Polish (interview prep, applications, final project touches)
