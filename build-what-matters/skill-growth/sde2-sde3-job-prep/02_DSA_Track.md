# DSA Track (16 Weeks)

## Objective

Solve **300+ DSA problems** with strong pattern recognition, speed, and clarity of explanation.

## Weekly Target

- **Weeks 1-8**: 25-30 problems/week (focus on patterns and fundamentals)
- **Weeks 9-16**: 20-25 problems/week (focus on hard problems, timed sets, contests)

## Practice Methodology

### Daily Routine (3-4 hours)

1. **Warm-up (15 min)**: Review yesterday's problem
2. **New Problems (2-2.5 hours)**: Solve 2-3 problems from current pattern
3. **Review (30-45 min)**: Write notes, complexity analysis, alternative approaches
4. **Spaced Repetition (15 min)**: Re-solve one old problem

### Weekly Routine

- **Monday**: Dedicated DSA day (4-5 problems)
- **Saturday/Sunday**: Timed contest simulation (4 problems in 90 min)
- **Wednesday**: Review weak patterns (1-2 problems)

### Problem-Solving Template

```java
// 1. Understand problem (read twice, write examples)
// 2. Brute force approach (time/space complexity)
// 3. Optimize (identify bottlenecks)
// 4. Implement clean solution
// 5. Test with edge cases
// 6. Explain complexity aloud

class Solution {
    public int[] solution(int[] nums) {
        // Implementation
    }
}
```

### Tracking Progress

- Use LeetCode's built-in progress tracker
- Maintain a personal notes file for each pattern
- Record time taken and difficulty rating for each problem
- Re-solve problems after 1 week and 1 month
